# CK v2ray 2.3.5-ck.8 — 订阅转换开箱即用

修复 Clash 订阅转换的 hy2 节点无法直接连接的问题(Xray core 26.2.6+ 禁止 allowInsecure)。

## 修复内容

- **hy2 自签证书自动固定**: 导入 Clash 订阅时, 自动按服务器去重并发抓取节点证书指纹(QUIC), 填入「证书指纹 SHA-256」并关闭"跳过证书验证" → 节点**导入即可用, 无需手动操作**
- **hy2 编辑页补「获取证书指纹」按钮**(上游遗漏): 自动抓取失败(如网络不可达)时可手动获取; 连上网络后重新更新订阅也会自动补抓
- 抓取按 server:port 去重(同机场仅几张证书), 导入延迟约 1-3 秒, 失败静默不影响导入

## 使用方式

添加/更新 Clash 订阅 URL 即可, 节点自动转换 + 自动固定证书指纹, 直接可连接。
